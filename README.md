## Projetos

São projetos pequenos, cada um resolvendo um problema que já encontrei no trabalho. Todos usam dados sintéticos, têm testes com pytest e passam no ruff.

| Projeto | O que faz |
|---|---|
| [multi-erp-etl](https://github.com/jamessalmom/multi-erp-etl) | Lê exportações em JSON e XML de ERPs diferentes e converte tudo para um mesmo esquema. |
| [star-schema-builder](https://github.com/jamessalmom/star-schema-builder) | Recebe uma tabela achatada, classifica as colunas e sugere fatos e dimensões no modelo Kimball. |
| [sql-kpi-toolkit](https://github.com/jamessalmom/sql-kpi-toolkit) | Consultas SQL parametrizadas com Jinja2 para Pareto, variação ano a ano e atingimento de meta. |
| [powerbi-dax-toolkit](https://github.com/jamessalmom/powerbi-dax-toolkit) | Um linter simples de nomes e legibilidade para medidas DAX, com exemplos de YTD, YoY, Pareto e RLS. |
| [crm-funnel-analytics](https://github.com/jamessalmom/crm-funnel-analytics) | Análise de funil de vendas e ranking de consultores, corrigindo dados do CRM sem alterar o original. |
| [pix-webhook-toolkit](https://github.com/jamessalmom/pix-webhook-toolkit) | Receptor de webhook com verificação HMAC e um cliente de saída com retry, backoff e idempotência. |

Outros: [flask-rbac-kit](https://github.com/jamessalmom/flask-rbac-kit) (controle de acesso por perfil no Flask, com login local ou LDAP), [flask-chartjs-dashboard](https://github.com/jamessalmom/flask-chartjs-dashboard), [resilient-api-client](https://github.com/jamessalmom/resilient-api-client), [incident-runbook-cli](https://github.com/jamessalmom/incident-runbook-cli), [ai-docstring-assistant](https://github.com/jamessalmom/ai-docstring-assistant), [analytics-patterns](https://github.com/jamessalmom/analytics-patterns), [pandas-regex-cookbook](https://github.com/jamessalmom/pandas-regex-cookbook) e [mapa-arquitetura](https://github.com/jamessalmom/mapa-arquitetura).
